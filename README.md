# Resume Website

A single-page resume website built with HTML and Tailwind CSS CDN. No build process required - just open and go!

## Features

- **Single-page layout** with sections for About, Experience, Projects, Skills, Education, and Contact
- **Responsive design** that works on desktop and mobile
- **Print-ready CSS** with optimized styling for PDF generation
- **Clean, professional design** using Tailwind CSS CDN
- **Zero dependencies** - no build process needed
- **GitHub Pages ready** for easy deployment

## Getting Started

1. Open `index.html` in your browser - that's it!
2. No installation or build process required

## Deployment

This site is configured for GitHub Pages. Simply push to the main branch and GitHub Pages will automatically deploy from the root folder.

## Customization

- Edit `index.html` to update your resume content
- Modify the inline styles in the `<style>` tag for custom CSS
- Update the Tailwind config in the `<script>` tag if needed

## Print/PDF Generation

The site includes print-optimized CSS. Use your browser's print function or the "Download PDF" button to generate a clean PDF version of your resume.

## Why Tailwind CDN?

- **No build process** - just open the HTML file
- **No dependencies** - works anywhere
- **Fast development** - instant changes
- **Perfect for static sites** like resumes
